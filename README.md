## Herramientas Desarrolladas
La página web implementa cinco herramientas lógicas independientes:
1. **IVA y Descuentos:** Cálculo de importes de IVA, precios con IVA y aplicación de descuentos comerciales.
2. **Conversor de Temperaturas:** Conversión bidireccional entre grados Celsius y Fahrenheit.
3. **Validador de Contraseñas:** Evaluación de seguridad basada en criterios de longitud, mayúsculas, minúsculas y números.
4. **Generador de Contraseñas:** Creación aleatoria de contraseñas seguras según la longitud y opciones seleccionadas.
5. **Contador de Palabras y Lectura:** Análisis de texto (conteo de palabras, caracteres, detección de la palabra más larga y estimación del tiempo de lectura).

## Estructura del Proyecto
* `index.html` — Estructura y diseño de la interfaz web por secciones.
* `estilos.css` — Estilos visuales adaptables (responsive) y diseño en formato de tarjetas.
* `funciones.js` — Lógica matemática, algoritmos de cálculo y funciones puras.
* `app.js` — Conexión entre la interfaz visual (DOM), validaciones y lógica de cálculo.
* `pruebas.js` — Batería de pruebas automatizadas mediante `console.assert`.
* `notas.md` — Apuntes, respuestas a cuestionarios y registro de incidencias.

---

## Pruebas Automatizadas
El proyecto incluye un sistema de pruebas unitarias (`pruebas.js`) que valida los casos límite y normales de cada función. Puedes ejecutar las pruebas directamente desde la interfaz web haciendo clic en el botón "Ejecutar pruebas" o revisando la consola del navegador (F12).
